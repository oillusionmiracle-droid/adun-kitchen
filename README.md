# Adùn Kitchen

A fictional firewood-fired Nigerian restaurant — concept website built as a portfolio demo.

- Single self-contained page (`index.html`): no build step, no dependencies.
- Editorial art direction: smoke-black, palm green, pepper red, bone.
- Motion system with a manual toggle and reduced-motion support.

> Demo concept. All restaurant details (address, phone, chef, prices, hours, story) are fictional.
